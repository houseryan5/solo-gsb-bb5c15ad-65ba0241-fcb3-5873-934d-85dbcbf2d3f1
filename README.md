# 🎭 剧场排练走位工具（Stage Blocking Tool）

在 **8 列 × 6 行** 的舞台网格上设置演员起点，**逐拍**指定每名演员
**上 / 下 / 左 / 右 / 原地** 动作，自动按拍推演全部演员位置，并标出：

- **撞格冲突**：同一拍两名以上演员处于同一格；
- **互换冲突**：相邻两拍两名演员互相交换了格子（交叉走位）；
- **越界拦截**：动作会把演员移出 8×6 舞台时被拦截，该演员该拍停留原位。

点击任意冲突条目，即可定位到对应的**拍、演员与舞台格子**（高亮闪烁 + 信息条说明）。
走位表保存在**浏览器本地（localStorage）**，刷新 / 关闭重开浏览器后可继续编辑，
无需登录、无需数据库、**无需任何第三方账号**。

---

## 一条命令启动（Docker Compose）

要求：已安装 Docker（含 Docker Compose 插件）。

```bash
docker compose up --build -d
```

启动完成后用浏览器访问：

> **http://localhost:3000**

停止：

```bash
docker compose down
```

> 启动流程已将依赖安装（`npm install`，本项目零第三方运行时依赖）与初始化全部
> 纳入容器构建 / 启动阶段，无需任何额外手动步骤。

## 不用 Docker 时的本地运行（可选）

要求：Node.js ≥ 18。

npm install        # 当前无第三方依赖，仅为兼容后续扩展

## 使用说明

### 1. 添加演员、设置起点

1. 在「演员」面板输入名字，点 **＋ 添加**（回车亦可）；
2. 点该演员的 **设起点** 按钮（或以后直接点舞台格子上的演员名字）；
3. 在舞台网格上点击一格作为起点。舞台方位：
   - 网格 **上方 = 后台（Upstage）**，**下方 = 舞台前沿 / 观众（Downstage）**；
   - 格子角标 `列·行` 与走位表坐标均为 **1 起始**。

### 2. 逐拍指定动作

右侧走位表中，每名演员每拍可选择：

| 选项 | 含义 |
| --- | --- |
| 上 ↑ | 向后台移动一格（行 −1） |
| 下 ↓ | 向观众移动一格（行 +1） |
| 左 ← / 右 → | 台口视角左右移动一格（列 ±1） |
| 原地 — | 本拍不动 |

**第 0 拍 = 起点**；第 N 拍的动作把演员从第 N−1 拍位置移到第 N 拍。

### 3. 越界拦截

- 在走位表下拉中选择会冲出 8×6 边界的动作时，立即弹出提示且该选择保留为**被拦截动作**
  （下拉框红框标记，舞台对应棋子显示 🚫 与“越界拦截”角标，冲突列表也会列出）；
- 推演时该演员该拍**停留原位**，后续拍次仍照常推演；
- 改成合法方向或「原地 —」后拦截自动解除。

### 4. 冲突检查与点击定位

右上方「冲突检查」按拍序列出全部 **撞格 / 互换 / 越界** 条目；
**点击任一条目**：

- 舞台自动跳到该拍；
- 对应格子金色边框闪烁（撞格红底、互换蓝底、角标文字区分）；
- 信息条显示「第几拍 · 演员 · 格子坐标」；
- 走位表同步定位到该拍列与该演员单元格。

### 5. 按拍推演

舞台下方控制条：⏮ 起点 / ◀ 上一拍 / ▶ 自动播放（或空格键）/ ▶ 下一拍 / ⏭ 末拍，
也可以拖动滑杆或用键盘 **← →** 切拍。总拍数（1–60）可在下方修改后点「应用」。

### 6. 保存 / 迁移

- 所有编辑（约 300 ms 防抖后）自动写入浏览器 **localStorage**，刷新页面后继续编辑；
- **导出 JSON / 导入 JSON** 可在不同电脑 / 浏览器间迁移走位表；
- **重置为示例** 清空本地数据并载入内置演示（内含撞格、互换、越界三种情形）。

## 内置示例看点

打开页面默认加载 3 名演员（甲 / 乙 / 丙）、8 拍走位：

- **第 3 拍**：甲、乙同时进入格子 (3, 3) → 撞格冲突；
- **第 7 拍**：甲 (3, 2) 与乙 (2, 2) 交换各自所在格子 → 互换冲突；
- **第 8 拍**：丙已在后台边缘 (5, 1) 仍执行「上 ↑」→ 越界拦截。

直接点击右侧冲突条目即可查看定位效果。

## 项目结构

```
.
├── Dockerfile              # Node 20 镜像，构建期安装依赖，启动即服务
├── docker-compose.yml      # 一条命令：docker compose up --build -d
├── package.json
├── server.js               # 零依赖原生 http 静态服务 + /healthz
├── .dockerignore
└── public
    ├── index.html          # 页面结构
    ├── styles.css          # 剧场暗色主题样式
    └── app.js              # 网格、逐拍推演、冲突检测、本地保存（原生 JS）
```

## 技术说明

- 后端：Node.js 内置 `http` / `fs` 模块提供静态页面，**零第三方 npm 依赖**；
  含目录穿越防护与 `GET /healthz` 健康检查；
- 前端：原生 HTML / CSS / JavaScript，无构建步骤、无前端框架、无外部 CDN；
- 数据：仅存于访问者浏览器 `localStorage`（键名 `stage-blocking-tool:v1`），
  服务端不保存、不上传任何走位数据。
